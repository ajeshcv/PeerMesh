## 📖 Overview

**PeerMesh** is an offline messaging application that enables users to communicate without relying on the internet or mobile networks. Using **Bluetooth** and **Wi-Fi Direct**, nearby devices automatically form a **mesh network**, allowing messages to travel across multiple devices through **multi-hop routing**.

Unlike traditional messaging applications, PeerMesh does not depend on centralized servers. Every connected device acts as both a communication endpoint and a relay node, ensuring reliable communication even in areas with no internet connectivity.
